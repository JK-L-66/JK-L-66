## 📂 Selected Projects

### [Representation Lab](https://github.com/JK-L-66/representation-lab)

An exploratory Python/PyTorch project investigating **translation representations and cross-shape generalization**.

- Implemented a shared CNN encoder to predict 2D image translations from differences between learned representations.
- Compared CNN predictions with an analytical centroid-based baseline.
- Evaluated generalization from squares to unseen circles and analyzed latent representation stability.
- Documented experimental results, limitations, and reproducible evaluation procedures.

**Key observation:** The CNN performed well on square images but systematically underestimated translation magnitudes on unseen circles, while the geometric baseline remained exact in the controlled setting.
